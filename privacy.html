快覆鍵盤私隱政策

你儲存的文字

你建立的回覆標題、完整文字、分類、最愛、排序及本機識別碼，儲存在裝置上的共用資料夾。主 App 和快覆鍵盤透過同一個 App Group 讀取這份資料；App 沒有把資料同步或上傳至我們伺服器的功能。搜尋字詞、未儲存的編輯及鍵盤試用文字，只用於當前介面，不會由本版本寫入回覆資料庫。

鍵盤如何使用資料

鍵盤會讀取已儲存的回覆，以顯示分類、最愛及文字列表。當你點選回覆，鍵盤使用 iOS 提供的介面把完整文字插入目前輸入欄。空格及刪除鍵只執行相應的輸入操作。訊息由你檢查及發送。

本版本不讀取輸入欄前後的文字、不建立打字紀錄、不讀取剪貼簿，亦不會掃描其他 App 的對話、聯絡人或相片。鍵盤不要求「完整取用」，沒有網絡傳送、廣告、分析、追蹤或第三方 SDK。插入文字後，目前使用的 App 會按其自身政策處理該文字；請自行決定是否發送及向誰發送。

JSON 備份與檔案服務

匯出的 JSON 包含所有已儲存的回覆及相關欄位，沒有 App 額外提供的密碼保護或檔案加密。App 先在自己的暫存資料夾建立一份完整 JSON，再由系統檔案選擇器複製到你指定的位置。取消匯出不會由 App 立即清除該暫存檔；日後匯出會覆寫同名暫存檔，系統亦可能清理暫存資料。

你可選擇本機檔案位置或自行設定的雲端檔案服務。該服務可能儲存或傳送檔案，並按其政策處理資料；這不是 App 傳送至我們的伺服器。匯入只讀取你透過系統選擇器選取的 JSON，驗證格式及數量，確認後才取代回覆資料庫。系統檔案服務可能建立自己的快取或副本。

請避免在回覆或備份中放入密碼、付款資料或不必要的客戶個人資料，只把備份存放在信任的位置。

保留、管理及刪除

回覆會保留在本機，直到你在 App 編輯、刪除，或以匯入取代。已匯出的備份、雲端副本、檔案服務副本及系統備份，需在相應位置另外管理；刪除 App 內回覆不會同時刪除這些副本。我們沒有伺服器上的回覆副本可替你恢復。本政策不承諾安全抹除或所有備份即時消失。

iOS／iPadOS 的裝置備份、系統診斷、輔助使用及 TestFlight 服務，可能按你的設定及 Apple 的政策處理資料。本 App 沒有自行加入分析或當機回報服務。

你主動聯絡支援

App 的電郵連結只會開啟你的郵件工具，不會自動附上回覆資料庫、打字紀錄或診斷檔案。只有你選擇寄出時，我們及所使用的電郵服務才會收到寄件電郵、你提供的內容及附件，並用作回覆及處理該次支援要求。請不要寄出密碼、完整客戶資料庫或未遮蓋私人資料的截圖。如需查詢或要求處理你提供的支援資料，請聯絡下方電郵。

政策及支援網站

這兩個靜態網頁沒有加入分析程式、追蹤像素、表格、外部字型或 JavaScript。網頁託管商仍可能處理必要連線資料。若使用 GitHub Pages，GitHub 的官方文件說明會為保安目的記錄訪客 IP 地址；相關處理亦受 GitHub 私隱聲明規管。這與離線 App 本身的資料處理分開。
